Chap 2: Installation Termux SANS ERREUR (la où 99% abandonnent)

ERREUR MORTELLE: Installer Termux depuis Play Store (version 2020 morte, ne marche plus).

BONNE METHODE:
1. Va sur f-droid.org avec Chrome -> Télécharge F-Droid APK -> Installe
2. Ouvre F-Droid -> cherche Termux -> Installe version 0.118+
3. Toujours dans F-Droid -> cherche Termux:API -> Installe
4. Ouvre Termux, tape:
pkg update -y && pkg upgrade -y
pkg install git nodejs termux-api -y
termux-setup-storage
termux-change-repo
Choisis Ghorgh-UK ou BFSU-Chine (plus rapide Bénin).
5. Crée ton dossier:
mkdir mon-site-timothee && cd mon-site-timothee && pwd
